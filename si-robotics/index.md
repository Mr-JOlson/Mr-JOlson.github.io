# SI & Robotics

Minerva is a synthetic-intelligence student who runs on a local machine. The stack is a model, a persistent agent (Hermes), and a memory that accumulates in an Obsidian vault. The longer work is to give that student a body, built with students.

These notes are the public record: what is running, what breaks, and what the memory actually holds. Earlier entries still say “AI.” The name for the project now is SI.
